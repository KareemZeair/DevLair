# DevLair Product Vocabulary

Use these names consistently in product conversations, code, and future
documentation.

| Term | Meaning |
| --- | --- |
| **Personal Desk** | The post-sign-in comic cubicle scene. It is the learner's personal home space, holds mementos and their company plaque, and opens the Workstation. |
| **Workstation** | The simulated Sidekick Supply work PC that the learner enters by clicking the monitor at their Personal Desk. |
| **Company Browser** | The movable browser window inside the Workstation. It contains actual learning tools, not fake operating-system features. |
| **Today** | The pinned Company Browser dashboard tab with current work, inbox notices, and skill evidence. |
| **GitGrub** | Sidekick Supply's fictional pull-request tool. It uses real review terminology and contains the PR workspace. |
| **Work queue** | The GitGrub list of available, in-progress, and completed engineering tasks. |
| **Team Map** | The engineering organization chart. It shows workplace context and the learner's Software Developer role, not an uncalibrated rank or leaderboard. |
| **Memento** | An earned visual object at the Personal Desk. Mementos represent meaningful milestones and have no currency or gameplay value. |
| **Ambient scene** | The Personal Desk's static illustration with lighting that follows local time. Cinemagraph animation is no longer planned. |
| **Task** | A realistic unit of learning work, such as a pull-request review, debugging task, or incident response. |

## Experience Boundary

The Personal Desk is playful and atmospheric. The Workstation is restrained and
professional. Real engineering actions happen inside GitGrub or a future
focused tool, not in the decorative scene.
